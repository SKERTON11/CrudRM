# CrudRM

Aplikasi CRUD sederhana menggunakan PHP Native dan MySQL.

## Deskripsi

Project ini merupakan aplikasi CRUD (Create, Read, Update, Delete) sederhana yang dibuat menggunakan PHP dan MySQL.

## Fitur

- Menampilkan data
- Menambah data
- Mengubah data
- Menghapus data

## Teknologi

- PHP Native
- MySQL
- XAMPP

## Cara Menjalankan

1. Jalankan Apache dan MySQL pada XAMPP.
2. Import database ke phpMyAdmin.
3. Letakkan project pada folder `htdocs`.
4. Akses melalui browser:

```text
http://localhost/CrudRM
```
